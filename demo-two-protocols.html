// what this shows

  • One layer, one selection. maui-zoning (layer 2) and one zoning-code predicate go through every protocol Honua serves for it. The three query doors share the Honua JS SDK's protocol-neutral contract (Dataset → Source → Query → Result); the two rendering doors draw the same layer on the same map.
  • 1 · GeoServices RESTCommunity
    The endpoints ArcGIS clients speak — /rest/services/…/FeatureServer/2/query.
    serve.geoservices-featureserver
  • 2 · OGC API FeaturesCommunity
    The open standard — /ogc/features/collections/…/items with CQL2 filters.
    serve.ogc-api-features
  • 3 · OData v4Community
    The same rows your spreadsheet and BI tools reach — /odata/Layers(2)/Features?$filter=.
    serve.odata
  • 4 · OGC API Tiles (MVT)Community
    Vector tiles of the whole layer, filtered on the client — /ogc/tiles/collections/…/tiles/WebMercatorQuad/{z}/{y}/{x}.
    serve.ogc-api-tiles
  • 5 · OGC API MapsCommunity
    The server renders the current map view as a PNG — /ogc/maps/collections/…/map?bbox=…&f=png.
    serve.ogc-api-maps

Every protocol surface — read, query, tiles, metadata — ships in the free Community edition (ELv2). That is the point: when every door is open and standard, the data is yours to walk out with.
