Claims and evidence by area
Claim area Supported claim and boundary Evidence
Runtime & single-binary platform One runtime serves the documented GIS, data, gRPC, and MCP interfaces. Architecture docs ↗
Web Console The public Console has a nightly image and is pre-1.0. Its Operate, Catalog, and Share surfaces bind to a server; the non-realtime Studio builders are shelved by default. A Console nightly is evaluation material, not a supported server-and-client release. Console status ↗ · Public image ↗
OGC & standards conformance counts The historical May 17, 2026 Honua-run snapshot passed 952/952 assertions across 11 scoped suites. It does not certify the current source or an evaluation image. Current source CITE status ↗ · OGC conformance ↗
GeoServices REST · GeoServer compatibility FeatureServer, MapServer, ImageServer, GeocodeServer, NAServer, GPServer, Geometry Service, and GeoServer migration cover common workflows. Long-tail exceptions are listed by operation. Parity matrix ↗ · Clients & limitations ↗
Migration wedge & cutover automation Assessment tools, GeoServices and GeoServer importers, and the public JavaScript codemod support staged migration. Unsafe conversions are flagged for review. Compatibility & migration evidence
gRPC & SDKs Typed gRPC services are included. The 2026.1 manifest pins are JavaScript @honua/sdk-js 0.2.10 and .NET release 1.12.0. The current Python release is honua-sdk 0.2.1. The newest public package is Honua.Sdk 1.13.1. That newer package is not the 2026.1 pin. Ecosystem & SDKs ↗
MCP & AI agent surface MCP supports discovery, schema inspection, filtered queries, statistics, and bounded spatial tools for agent workflows. geospatial-mcp
Mobile · field · offline · MAUI Mobile SDK source is available. Connected field workflows require pilot access. Some offline-sync routes are not yet implemented. honua-mobile
Deployment & AI DevOps loop Helm, health/readiness endpoints, and OpenTelemetry are included. The governed one-environment operator requires pilot access; coordinated fleet promotion is not yet implemented. Helm chart · operator program
Performance benchmarks The April 28, 2026 GeoBench snapshot publishes the test profile and results. Use it as a dated comparison, then benchmark your own workload. GeoBench harness · historical snapshot and limits
Commercial tiers & pricing Honua Server is source-available under FCL-1.0-ALv2 ↗; the SDKs are Apache-2.0. The 2026.1 evaluation configuration disables licensing, so all catalog entitlements are active.
