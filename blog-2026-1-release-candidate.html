What the Release Candidate is.

Honua is a geospatial platform for AI agents and people working on the same data: Honua Server, SDKs for JavaScript, Python and .NET, an MCP server for agents, and Honua Studio for AI-assisted map making.

One server serves PostGIS-backed data through GeoServices REST, the OGC APIs, WMS, WFS, WMTS and WCS, STAC, OData and vector tiles. Honua Server is Fair Source under FCL-1.0-ALv2; the SDKs, Console and Studio are Apache-2.0.

Use the Release Candidate to evaluate Honua and run pilots. The GA commitments below apply from the GA release. The GA release record lists the qualification evidence collected for that candidate.

GA, Preview and Experimental.

GA: Docker Compose and AWS ECS deployments, with the protocol surfaces, SDKs and Console listed in the release notes.

Preview: the Helm chart on Amazon EKS and other Kubernetes distributions, AWS Lambda, the geoprocessing (GP) catalog and Honua Studio, along with realtime and geofence alerting, offline sync, OGC API EDR, OGC SensorThings and branch versioning. Preview surfaces ship in the release and are documented. Their functional results do not gate the release, and they may change. Security, isolation and integrity checks still apply to them.

Experimental: 3D Tiles scenes, CityGML/BIM and point-cloud ingest, I3S, the mobile SDK and Honua Collect.

Every supported 2026.1 deployment is single-tenant and runs on x86_64.

Supported SDK versions.

  • JavaScript and TypeScript: @honua/sdk-js 0.2.10 ↗
  • Python: honua-sdk 0.1.19 ↗
  • .NET (net10.0): Honua.Sdk 1.12.0 ↗

The .NET SDK has no OGC API Tiles client in 2026.1. The server's Tiles endpoints work the same for every client, and .NET applications can call them over HTTP.

Known issues.

  • demo.honua.io runs without Redis. We disconnected Redis from the public demo on 2026-10-24 after finding a defect in Redis-connected serving on AWS Lambda (honua-server#6558 ↗). The fix is in review (honua-server#6644 ↗). Until Redis is reconnected, MapServer and ImageServer image exports on the demo return a capacity error, and features that need a Redis job store are refused with a typed error.
  • Preview surfaces. Helm, AWS Lambda, the GP catalog and Studio are in the Release Candidate but do not gate it. Report problems as issues; these surfaces may change before GA.
  • Two .NET certification cells are declared blocked. OGC API Tiles through Honua.Sdk has no client (honua-sdk-dotnet#405 ↗), and published-SDK service-layer import fidelity has no evidence producer yet (honua-release#418 ↗). Both are targeted at 2026.1.x.

Known limitations that are not specific to the Release Candidate are listed in the release notes. Two examples: imported attributes are stored in one JSON properties column until typed columns arrive in 2026.1.x, and WMTS serves WebMercatorQuad only.

Upgrade notes.

Breaking change. API keys granted only admin:write or admin:manage now receive 403 when they create, rotate or revoke API keys, change user roles, deprovision users, or register or delete OAuth clients. They keep read access to those resources. Before you upgrade, move automation that manages credentials to a full-administrator credential or to an approved operation.

Nightly images and earlier pre-release snapshots carry no upgrade guarantee. Take a database backup before moving one to the Release Candidate, and follow the upgrade runbook.
