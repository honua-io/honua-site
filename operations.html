// runs on what you already run

Built from cloud primitives, not retrofitted onto them.

Every layer is a cloud primitive your platform team already operates — named in your IaC, billed on your existing cloud account, governed by your existing identity provider.

01 · Containers, serverless, batch OCI containers on the orchestrator you already operate.

EKS, AKS, ECS / Fargate, or plain Docker. Per-request paths — feature queries, tile renders, MCP tool calls — deploy to Lambda, Azure Functions, or Cloud Run and scale to zero. Long-running work lands on AWS Batch, Azure Batch, or K8s Jobs.

02 · PostGIS and object storage The database you trust stays the system of record.

Features live in PostGIS. Rasters, tiles, and styles live in S3, Azure Blob, or MinIO — versioned, immutable, range-fetched. GeoParquet and COG are read in place, so analytics doesn't start with an import.

03 · Your identity provider OIDC-first. One audit log.

Map IdP groups to Honua roles — Entra ID, Cognito, Okta, Auth0, Keycloak. Humans, services, and the agent loop act under the same identity and land in the same audit log. There is no separate user table to sync.

// fast by default

Performance is engineering, not tuning.

01 · AOT-compiled No JIT warmup. Low memory floor.

The engine compiles ahead-of-time with .NET NativeAOT. Cold starts are quick enough that scale-to-zero is practical, and the same binary runs on ECS, AKS, Lambda, or your laptop.

02 · Benchmarked in the open Public methodology, repeatable results.

p50 / p95 / p99, RPS, and cold starts are measured in the open geobench suite — run it against your own workload and check our numbers.

03 · CDN-friendly by design Cacheable URLs, strong ETags.

Tile and feature responses cache cleanly at the edge. Put a CDN in front and the long tail of map traffic never reaches the server.
