Choose a deployment shape that matches the evidence.

The certified 2026.1 GA deployment architecture is the AWS CloudFormation Launch Stack on ECS Fargate (x86_64) with RDS PostGIS and Console in S3/CloudFront. Use Docker Compose for local evaluation, and add Kubernetes or GitOps only where current evidence supports your workload.

Honua Server runs on .NET 10, ships as an immutable OCI container image, stores features and durable control-plane state in PostgreSQL/PostGIS (zero Redis), and emits OpenTelemetry. The certified GA install path is the native AWS CloudFormation Launch Stack on ECS Fargate (x86_64). Public honua-iac Terraform modules and the honua-helm chart cover the additional paths below.

Compare the component relationships in the interactive AWS view or Azure view; use this page for the explicit evidence status behind those shapes.

Cross-cutting principles

  • Familiar interfaces on one server. A single Honua deployment exposes documented GeoServices REST, OGC API Features, WMS, WFS, WMTS, WCS, and STAC surfaces. Coverage varies by protocol and operation; see the Compatibility Matrix.
  • Stateless server tier, PostGIS-backed state. Scale the Honua server tier horizontally; keep catalog, durable job queues, workflow state, and features in PostgreSQL/PostGIS, and store artifacts in object storage (no Redis).
  • Observability by default. OpenTelemetry traces/metrics from the server tier into the operator's existing backend.
  • Shared security boundary. Honua documents TLS termination, authentication options, policy-scoped authorization, and structured security events. The deploying team owns infrastructure controls by default. Durable audit storage and compliance dashboards are not baseline server features; see Security & DPA.

A. AWS CloudFormation Launch Stack (ECS Fargate x86_64) — certified GA

The certified 2026.1 GA architecture deploys Honua into your AWS account with one native CloudFormation stack: CloudFront + AWS WAF over a private VPC origin to an internal ALB, stateless ECS Fargate (x86_64) tasks pinned by image digest, encrypted RDS PostgreSQL 16/PostGIS, S3/CloudFront static Console, Secrets Manager/KMS key-ring protection, and an independent watchdog.

C. Cloud-native HA on Kubernetes / EKS (Preview)

The public Helm chart describes a horizontally scaled server tier behind an ingress, with managed PostgreSQL/PostGIS and shared object storage. Kubernetes/Helm and AWS Lambda are Preview in 2026.1; use the AWS CloudFormation Launch Stack on ECS Fargate (x86_64) for the certified GA path.

Deployment limits

No production sizing recommendation.

The diagrams are illustrative. They do not prescribe cloud sizing, replica counts, PostGIS tiers, or object-storage settings.

No general capacity rule.

Honua has not published a requests-per-pod rule. The dated GeoBench profile is benchmark evidence, not a production sizing calculator.

No compliance certification.

SOC 2 Type II remains planned; no certification or report is currently available.

No marketplace install.

AWS and Azure Marketplace listings and one-click deployment URLs are not currently available.
