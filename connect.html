Connect the tools you already use in five minutes.

A live Honua demo server runs at demo.honua.io, seeded with public Maui datasets (zoning, buildings, roads, flood hazard, hillshade). Every endpoint below answers anonymously — paste a URL into your desktop client and you are looking at Honua-served layers before your coffee cools.

Jump to your tool: QGIS · other desktop GIS · Excel and Power BI · AI agents · your own applications. For every protocol the demo enables, with a live status check, see all demo endpoints.

The demo server is a shared evaluation instance with no uptime commitment. It doesn't replace checking your own workflows, operation by operation, against the compatibility matrix. Client behaviour differs by version, so record what you test.

These protocols are exercised, not just published. Recorded CI interop lanes run a desktop QGIS lane against WMS, WMTS, WFS, and OGC API Features, and a GeoServices REST client lane against FeatureServer and MapServer. The dated lane records live on each capability's evidence page — for example WMS and FeatureServer.

QGIS

  • WMS / WMTS: in the Browser panel, right-click WMS/WMTS → New Connection…, paste the WMS or WMTS URL above, then expand the connection and drag a layer (for example maui-zoning) onto the map.
  • WFS / OGC API Features: right-click WFS / OGC API Features → New Connection… and paste either the WFS GetCapabilities URL or the OGC API Features URL — QGIS handles both through the same connection type. Feature layers load with attributes you can identify, filter, and export.
  • Vector tiles: right-click Vector Tiles → New Generic Connection…, paste the vector tile URL above as the URL template (keep the {z}, {y} and {x} placeholders exactly as written: OGC API Tiles puts the row before the column), set min zoom 0 and max zoom 18, and optionally set the style URL to https://demo.honua.io/api/styles/2.json. Written for QGIS 3.34 LTR or later; generic vector tile connections have been in QGIS since 3.14. The demo has no GeoServices VectorTileServer, so use this connection for vector tiles.
  • GeoServices REST: right-click ArcGIS REST Servers → New Connection… and paste https://demo.honua.io/rest/services to browse the same datasets through the GeoServices surface.

Other desktop GIS clients

  • WMS / WMTS: add the matching URL above as a new WMS or WMTS server connection, leave credentials empty, and add layers from that connection.
  • GeoServices REST: desktop clients that speak GeoServices REST, listed in the client compatibility table, can add https://demo.honua.io/rest/services/maui-buildings/FeatureServer/0 as data to load the buildings layer, with attribute queries served by Honua's GeoServices REST surface.
  • Coverage caveat: desktop clients exercise many operations per workflow; supported operations are tracked per client in the client compatibility matrix. If an operation misbehaves, that matrix is the first place to check whether it is a known gap.

Excel and Power BI

  • Excel: choose Data → Get Data → From Other Sources → From OData Feed, paste https://demo.honua.io/odata/, and pick a table in the Navigator.
  • Power BI Desktop: choose Get data → OData feed and paste the same URL.
  • What is tested: the OData v4 endpoint is covered by the server's own tests. Honua has not published a dated Excel or Power BI run yet, so if a table does not load, tell us what you saw.

AI agents

  • MCP endpoint: add https://demo.honua.io/mcp as a remote MCP server (streamable HTTP) in an agent that supports one. The demo answers without credentials.
  • What the agent gets: tools to discover the demo's services and query their features, under the same permissions as any other client.
  • See it first: the demos include an agent working through a proposal, an approval, and a bounded result.

Your own applications

  • Start from working code: the runnable samples gallery has browser examples against the demo server.
  • SDKs: there are packages for JavaScript, Python and .NET. The API reference has the request and response contracts.
  • Existing ArcGIS JavaScript code: the codemod sample shows what the automated rewrite changes and what it flags for review.

Verify what you tested

A five-minute connection proves the wire protocol. It doesn't prove your workflow. When you evaluate seriously, note the client version, the operations you ran (identify, filter, edit, print), the authentication flow, and compare against the client compatibility matrix and capability catalog — each row links dated evidence.

Want this with your own data? Send one public service URL and we will show you a copy of it running on Honua, in these same clients.
