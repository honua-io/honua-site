Know what you can install before you integrate.

2026.1 ships with licensing disabled.

All catalog entitlements are active. No license file, minting or edition gating is required; serving-unit bands are neither measured nor enforced. Authentication, authorization, safety limits and capability maturity still apply. Alerting and offline sync remain Preview; multi-tenancy is internal (ruling R29).

Edition assignments, license pricing and capacity bands on this page describe 2026.2 intent, not requirements for 2026.1. Licensing hardening, metering and marketplace automation are deferred to 2026.2. The supported operating envelope defines qualification limits. FCL-1.0-ALv2 source-license terms and paid service agreements still apply.

Package availability, source availability, and version compatibility are different promises. This page states each one separately for the Honua SDKs. For GeoServices REST operation coverage and desktop-client workflows, see the client compatibility matrix.

Check the Honua capability contract

Honua SDKs inspect GET /api/v1/admin/capabilities. The response reports the Honua server version, release channel, control-plane API version, metadata schemas, and feature flags used for compatibility decisions.

Read it with the published Python admin client, honua-admin 0.2.1, the current release. Set HONUA_URL to the server and HONUA_API_KEY to its admin password or an admin-scoped API key:

pip install honua-admin==0.2.1
python3 - <<'EOF'
import os
from honua_admin import HonuaAdminClient

admin = HonuaAdminClient(os.environ["HONUA_URL"], api_key=os.environ["HONUA_API_KEY"])
print(admin.get_capabilities().compatibility)
EOF

/rest/info is intentionally a GeoServices REST discovery endpoint. Its currentVersion value describes that protocol surface; it is not the Honua release version.

How availability is verified

Honua lists a package as publicly installable only when its registry endpoint resolves. A supported version window requires released SDK and server artifacts plus recorded cross-version evidence. CI checks the generated table and registry state independently.
