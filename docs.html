Local setup

Choose a source build or a packaged deployment.

The canonical quickstart builds from source. The deployment guide supplies an inline Compose file for a published server image.

STEP 01Prerequisites
STEP 02Build and start
STEP 03Verify

Source quickstart prerequisites: Docker with Compose v2, Git, GitHub CLI authenticated with package-read access, Python 3.11 or later, and Bash for the published shell commands. The quickstart builds the server with a GitHub Packages build secret, then starts PostGIS, Redis, and Honua. A bare docker compose up -d does not replace that build step.

Follow the full quickstart for the build, local configuration, Python client installation, publication, and query verification. Check readiness at http://localhost:8080/healthz/ready in a browser; expect Ready.

Open the source quickstart ↗Open the packaged deployment guide ↗

Windows and package-only evaluation: the linked guides currently show Bash commands, and the source quickstart installs Python clients from Git. They do not provide a complete native PowerShell, package-only walkthrough. Check published SDK availability before choosing a client. To upload your own GeoJSON after setup, continue with Your first dataset ↗.

Pin what you evaluate: record the source commit with git -C honua-server rev-parse HEAD for a source build. For a packaged deployment, use the immutable image reference supplied by its release manifest. When evaluating the current public ghcr.io/honua-io/honua-server:trunk package before a release, pull it first, then record its digest with docker image inspect --format '{{index .RepoDigests 0}}' ghcr.io/honua-io/honua-server:trunk. A current-package evaluation is not a certified release; repeat it against the exact release candidate after the cut. Questions go to GitHub Discussions ↗.

Building with a coding agent or IDE assistant? Machine-readable SDK docs ship at /llms.txt (curated index) and /llms-full.txt (single-fetch corpus), commit-pinned with SHA-256 provenance. A live API console runs at demo.honua.io/docs ↗.
