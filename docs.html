2026.1

2026.1 ships with licensing disabled.

Set Licensing__Mode=Disabled in the server and worker environments. After startup, authenticate to GET /api/v1/admin/license and require data.mode: disabled. Use the release installation settings.

All catalog entitlements are active. No license file, minting or edition gating is required; serving-unit bands are neither measured nor enforced. Authentication, authorization, safety limits and capability maturity still apply. Alerting and offline sync remain Preview; multi-tenancy is internal (ruling R29).

Edition assignments, license pricing and capacity bands on this page describe 2026.2 intent, not requirements for 2026.1. Licensing hardening, metering and marketplace automation are deferred to 2026.2. The supported operating envelope defines qualification limits. FCL-1.0-ALv2 source-license terms and paid service agreements still apply.

Learn Honua’s terms.

A Dataset contains data. Its kind is Feature type for vector data or Coverage for raster data; a non-spatial Feature type is shown as a Table. A Layer exposes a Dataset through a Service. Folders group Services, and an Environment is one Honua server managed by Console.

Studio is Preview. Each supported kind keeps its own name, including Map, App, Dashboard and Workflow. Draft, Version and Released describe the lifecycle of supported Studio kinds.

The full quickstart covers configuration, publishing, verification, and troubleshooting.

# prerequisites: Docker Compose v2, Python 3.11 or later; port 8080 free
# 2026.1 runs with licensing disabled. Do not set a development edition grant.
export HONUA_SERVER_IMAGE="ghcr.io/honua-io/honua-server:2026.1-rc"
export HONUA_ADMIN_PASSWORD="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
export HONUA_MASTER_KEY="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
cat > compose.yaml <<'EOF'
name: honua-fast-lane
services:
  db:
    image: postgis/postgis:16-3.4
    environment:
      POSTGRES_USER: honua
      POSTGRES_PASSWORD: honua
      POSTGRES_DB: honua
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -h 127.0.0.1 -U honua -d honua"]
      interval: 3s
      timeout: 3s
      retries: 30
  honua:
    platform: linux/amd64
    image: ${HONUA_SERVER_IMAGE:?Set HONUA_SERVER_IMAGE to ghcr.io/honua-io/honua-server:2026.1-rc}
    depends_on:
      db:
        condition: service_healthy
    environment:
      ASPNETCORE_ENVIRONMENT: Development
      ConnectionStrings__DefaultConnection: Host=db;Port=5432;Database=honua;Username=honua;Password=honua
      HONUA_ADMIN_PASSWORD: ${HONUA_ADMIN_PASSWORD:?Set HONUA_ADMIN_PASSWORD}
      Security__ConnectionEncryption__MasterKey: ${HONUA_MASTER_KEY:?Set HONUA_MASTER_KEY}
      Licensing__Mode: Disabled
      HostValidation__AllowedHosts: "*"
      AllowedHosts: "*"
    ports:
      - "127.0.0.1:8080:8080"
    healthcheck:
      # The server image ships bash but no wget or curl: the authenticated request goes over /dev/tcp.
      # Only an exact 200 counts; the headers are skipped and the mode is read from the body.
      test: ["CMD", "bash", "-c", "exec 3<>/dev/tcp/127.0.0.1/8080 && printf 'GET /api/v1/admin/license HTTP/1.0\\r\\nHost: localhost\\r\\nX-API-Key: %s\\r\\nConnection: close\\r\\n\\r\\n' \"$$HONUA_ADMIN_PASSWORD\" >&3 && IFS=' ' read -r proto code rest <&3 && [ \"$$code\" = 200 ] && while IFS= read -r line <&3 && [ $${#line} -gt 1 ]; do :; done && grep -Eq '\"mode\"[[:space:]]*:[[:space:]]*\"disabled\"' <&3"]
      interval: 5s
      timeout: 5s
      retries: 60
      start_period: 20s
EOF
docker compose -f compose.yaml up -d --wait
docker compose -f compose.yaml ps

# healthy: continue with import, publish, and map verification

Stop the stack when you are done. This releases port 8080.

docker compose -f compose.yaml down -v

Pin what you evaluate: the fast lane runs the server image you name, not a build of a checkout. The compose file sets platform: linux/amd64 on the server and Licensing__Mode to Disabled. It does not set a development edition grant. 2026.1 qualifies x86_64 only. An arm64 host runs that child under emulation and is not a supported 2026.1 topology. The 2026.1 Release Candidate image is ghcr.io/honua-io/honua-server:2026.1-rc (server 2026.1-rc.1). A nightly image is not this pin. On Windows with Docker Desktop Linux containers, use the Windows quickstart. Record the digest it resolves to (docker image inspect --format '{{index .RepoDigests 0}}' "$HONUA_SERVER_IMAGE") and re-run comparisons against that pin. Questions go to GitHub Discussions ↗, the public community channel.

If you build with a coding agent or IDE assistant, machine-readable SDK docs ship at /llms.txt (curated index) and /llms-full.txt (single-fetch corpus), commit-pinned with SHA-256 provenance. A live API console runs at demo.honua.io/docs ↗.

Your own data: the quickstart publishes a bundled table. To upload and publish your own GeoJSON after setup, continue with Your first dataset ↗.
