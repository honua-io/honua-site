// honua-gis · public evaluation track

A GIS evaluation harness.
No model weights are published yet.

Honua-GIS is a research track for a planned GIS-focused coding and workflow model. Today you can inspect a 50-prompt benchmark, deterministic graders, report schema, baseline runbooks, model-card scaffold, and packaging workflows in the public repository. No fine-tuned Honua-GIS weights, model-quality results, pullable Ollama tag, or NIM image are published yet.

Evidence snapshot: honua-gis-llm commit 8ddf9331417d28644cb650c3eb67f92193ac337f. Honua-GIS is separate from the private-beta honua-devops operator and the Honua GIS Assistant QGIS plugin.

// limitations

Current limits.

No released quality claim

No completed gis-workflow-eval reports or pass rates are published, so no comparison with a base or closed model can be made.

No production readiness claim

The model-card scaffold says outputs require human review and must not be used for emergency, legal, surveying, permitting, environmental compliance, or safety decisions.

No public pull command yet

Neither an unprefixed nor a namespaced Ollama pull command is available without a published namespace URL, tag, and GGUF checksum.

No verified NIM path yet

Exact NIM commands require published entitlement instructions, an endpoint or image identifier, and completed smoke evidence.
