This SDK compatibility article has been withdrawn.

Formerly KB-COMPAT-0001 · withdrawn July 10, 2026

The previous article paired SDK and server versions without released public packages or reproducible cross-version evidence. Do not use those instructions.

Current guidance

  • Use the public SDK availability page for installable packages and stated compatibility boundaries.
  • Read the Honua server version and capability contract from GET /api/v1/admin/capabilities.
  • Do not use the compatibility currentVersion from /rest/info as the Honua release version.
  • Do not install an SDK version unless it resolves from the linked public registry or an explicitly documented source-preview workflow.

Need help with a specific pairing?

Send the SDK package name, installed version, server capability response, and failing request. Until a replacement article is published, the SDK availability page and the server capability response are the current guidance.
