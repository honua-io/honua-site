What this page does not fake

        
    
          
  • Every control above is an SDK element or SDK function. Page code only places them, feeds them data, and reacts to their events. The cursor coordinate readout and the tab strip are the only page-owned widgets.
    • 
          
  • Live first. Layers stream from OGC API Tiles and the GeoServices FeatureServer on demo.honua.io. If a request fails, the status pill and the layer note say which one; nothing is swapped for a fixture.
    • 
          
  • Not shown: sketch/edit (needs the optional terra-draw peer and a writable layer — see the editing demo), routing/directions (the demo server has no route service), and @honua/sdk-js/share (it governs access-denial and embed tokens, not link building — the share link here is built from the interaction and filter-registry codecs).
    •
