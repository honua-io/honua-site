Build a new application with gRPC and files.

Run the browser setup with geospatial-grpc and Connect's gRPC-Web transport for authenticated live queries and edits. Public, read-heavy data belongs in PMTiles, GeoParquet and COG files over HTTP range requests through your CDN, because gRPC is not CDN-cacheable. Private files use signed URLs and are regenerated when source data changes.

The guide distinguishes customer-operated file delivery from server capabilities. The OGC API and GeoServices REST examples below are compatibility paths for existing clients.
