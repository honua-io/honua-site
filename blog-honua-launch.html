What Honua is.

One server serves your PostGIS data to the clients you already run: ArcGIS Pro, QGIS, MapLibre and Esri Leaflet, over GeoServices REST, the OGC APIs, WMS, WFS, WMTS and WCS, STAC, OData and vector tiles. SDKs for JavaScript, Python and .NET. An MCP server so agents can discover and query the same services. Honua Studio (Preview) builds a map from a description.

Operations are typed and policy-gated: every operation can require an approval or a dry run, and protected updates check their recovery plan before they activate (release notes, “Operate safely” ↗). The AI operator that proposes and applies changes through that control plane is private tooling and is not part of the Release Candidate; the Ops Inbox walkthrough shows how it works. That is what we mean by AI-native: agents and people act on the same services, through the same approvals, with the same rollback.

Honua Server is Fair Source (FCL-1.0-ALv2 ↗); the SDKs, Console and Studio are Apache-2.0. We believe a map server should be boring to operate, standards-friendly, inspectable, and easy to leave.

What is true today.

2026.1 is a Release Candidate. GA tier: Docker Compose and AWS ECS. Preview: Helm, AWS Lambda, the geoprocessing catalog and Studio. Not in the release: the AI operator (private tooling). Every supported deployment is single-tenant on x86_64.

Known issues, listed before you find them:

  • Throughput is lower than earlier pre-release builds: a security fix removed a blanket cache for anonymous reads, and the capacity envelope is re-frozen at 357 requests per second on four CPUs.
  • Preview surfaces may change before GA.
  • The server's capability catalog still labels the geoprocessing catalog GA; its 2026.1 tier is Preview, and the label fix ships in the next candidate.
  • Two .NET certification cells are declared blocked.

The full list, with the issue behind each line, is on the release page.

Clients that already work.

ArcGIS Pro 3.4, QGIS 3.40, MapLibre and Esri Leaflet connect to the Release Candidate. The compatibility and support table ↗ in the release notes lists each client and surface. Honua is compatible with these clients; it is not affiliated with or endorsed by their vendors.

When it breaks.

In a signed pilot or OEM agreement, a P1 gets a first response within 4 business hours and an update at least every business day until it is mitigated. Coverage is business hours, Monday to Friday in Hawaii time; 24×7 response is not offered. We take two engagements at a time so that this holds.
