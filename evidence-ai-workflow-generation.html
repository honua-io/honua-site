AI Workflow and Content Generation is retired

The former server-side generation capability has been removed from the capability catalog and licensing feature list.

This URL is retained for existing bookmarks. Its former Pro badge and evidence counts no longer describe a shipping capability.

What remains available

The MCP tools honua_create_map_package and honua_create_app_package create draft packages deterministically from structured client input. They perform no server-side model inference and do not accept natural-language prompts.

Package composition is separate from applying or executing a plan. The retired Pro generation entitlement does not apply to these draft tools; caller authorization still applies. Spec Apply Execution remains Pro-gated.

See the server retirement and deterministic package-creation change for the implementation and scope decision.
