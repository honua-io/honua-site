// what this shows

  • Vector tiles, straight from the server. Maui zoning and 51,245 parcels come from OGC API Tiles (/ogc/tiles/collections/…/tiles/WebMercatorQuad/{z}/{y}/{x}, source-layer layer). serve.ogc-api-tiles
  • Category style + legend. One color table paints the map and writes the legend, keyed on the first digit of zone_code. styling.defaults
  • Click → connect → explain → mount → query. The SDK discovers maui-parcels/FeatureServer/1, explains the point-in-polygon plan, mounts the matching parcel, and reads it back for the popup. query.features serve.geoservices-featureserver
  • Fly to an address. World/GeocodeServer/findAddressCandidates on the same server. Try “Kahului Airport”. geocoding.forward

Why zoning and not parcels for the colors: the Maui parcel layer carries only a TMK tax-zone digit (1–6), not a land-use class. So the categories come from maui-zoning (layer 2) under the parcel lines, and the popup combines both.
