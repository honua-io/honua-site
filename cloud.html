// what honua cloud is

Honua's runtime, without operating the server.

The planned service will expose documented Honua protocol surfaces without asking your team to deploy or upgrade Honua Server. Only the early-access list is available today; Honua Cloud is not. Final packaging and service commitments will be published before invitations begin.

Same server, same protocols
The planned service will host the documented GeoServices REST, OGC, OData, gRPC, and MCP surfaces. Existing clients still require operation-level compatibility validation before an endpoint move.
Capacity-based packaging
The intended model prices workload capacity rather than named users. Final Cloud bands, inclusions, and billing terms will be published before the service is offered.
Planned server operations scope
The planned service covers Honua Server provisioning, upgrades, and health monitoring. Backup, failover, and data responsibilities will be explicit in the published responsibility model.
Planned data ownership and exits
Data placement, backup ownership, export, identity, regions, and key management will be defined before early access. Standards-based interfaces reduce switching cost, but moving providers can still require endpoint, identity, configuration, and operational changes.
