Honua's AI-assisted operator surface is in private beta. Explicit policy may graduate deterministic low-risk actions, while risky or irreversible work remains approval-gated. Each tool action produces a structured, redacted record. // the safety architecture

Guardrails are the architecture, not a setting.

None of these are toggles a model can flip mid-conversation. The gates live in the tool handlers and the engine, fixed at registration time by whoever configures the server — an MCP client cannot escalate them.

01 · Plans before actions
Plan mode and PR-first are enforced defaults. Planning tools emit plans and evidence bundles; they do not apply manifests. A separate deterministic action path requires explicit policy graduation and passes through the same release gates.
02 · Proposals first, narrow graduation
Configuration and metadata changes default to GitOps proposals for review. Only deterministic low-risk actions can be explicitly graduated; post-action convergence evidence is still being completed, so broader autonomy remains off-limits.
03 · Audit by default
Every operator tool call emits a structured record with argument redaction. Configure durable storage and retention externally; Honua does not claim a tamper-evident compliance audit store today.
04 · AI cannot edit your data
An engine-level architecture decision, not a config flag. Agents never write features directly; data and config changes go through validated specs with dry runs before anything applies.
05 · Scoped credentials
Use bearer/session identity where the host supports it and a narrowly scoped API key only as an explicit compatibility fallback — never the admin password. The credential bounds what a conversation can reach.
06 · Your models, your GPU
Run the agent loop against local models — vLLM or Ollama on hardware you control. No data leaves your network to get the assistance.

// the honest roadmap note

Where the guardrail ladder goes next.

Today the private-beta operator starts plan-first and PR-first, records each tool action, and routes rollback tools through policy and release gates. Deterministic low-risk execution exists behind explicit graduation. Post-action convergence, failure-of-failure handling, signed cross-repository promotion, and fleet control must land before we claim a self-healing production loop. How we hold ourselves to that →
