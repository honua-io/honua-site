01 · Migrate, compose portal pages & make maps

Drive migration, Studio mapmaking, and open-data portal publishing with AI.

The public MCP discovery and query surfaces are available now. Connect your personal AI agent to /mcp or enable Amazon Bedrock in your AWS Launch Stack to inventory and import services, run @honua/honua-migrate codemods on JavaScript and Python apps, and use the 19 honua_studio_* tools to compose versioned maps, dashboards, multi-page apps, and narrative open-data portal reports that pull directly from your live services, charts, and tables. When approved for public indexing, Console and Server automatically project your datasets to /public, DCAT-US 3.0 data.json, Schema.org Dataset JSON-LD, OGC API Records, and STAC. 02 · Operate one environment PILOT ACCESS

Turn an incident or CVE patch into a reviewable Ops Inbox plan.

honua-devops and the server control plane inspect health, metrics, and errors; explain likely causes; plan a deployment or @sha256 CVE image rollout; and draft a GitOps proposal or sealed Console Ops Inbox proposal. Planning does not apply changes. A narrowly scoped policy can permit specific deterministic actions (including an "Automatically apply this rule in the future" policy toggle backed by a tamper-evident HMAC-SHA256 audit chain), and each tool call produces a redacted structured record.

03 · Fleet automation PARTIAL

Verify and recover are implemented. Fleet promotion is next.

Every autonomous action is verified after the fact and compensated when it fails to converge. An action with no registered verifier is refused rather than executed. Cross-environment fleet promotion is not yet implemented.

Your MCP client or in-account Amazon Bedrock model supplies reasoning. Honua's credentials, tool permissions, action policy, and approval flow bound what that model can reach. Review the evidence and limits →

Less operational toil, and no blank check.

The operator starts by gathering evidence. Configuration changes go through a validated specification and dry run, then default to a pull request for human review. Explicit policy is required for the narrow action paths that can apply a change. Diagnosis, approval, and execution remain separate steps.

Evidence first

Health, telemetry, and error signals support a diagnosis, ranked remediation steps, and checks your team can review.

Scoped authority

Tool handlers enforce credentials, permissions, and approval rules. Conversation instructions cannot expand them.

Recorded actions

Tool calls emit redacted records. Your deployment supplies durable storage, retention, and any compliance controls.
