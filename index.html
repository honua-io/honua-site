Keep your possibilities open.
Move the whole system forward.

01 / BRING

Bring what you have.

Move from ArcGIS, GeoServer, and existing infrastructure with automated service and data imports and code conversion for supported workflows. Migrate incrementally, preserving the tools and integrations that matter.

Explore migration documentation ↗
02 / CREATE

Build what comes next.

Describe the map or spatial app you need, refine it conversationally, and see the composition change as you work. Extend through SDKs, APIs, and permissioned AI workflows.

Preview Studio is self-hosted; see the walkthrough for its current scope.

Inside AI mapmaking ↗
03 / SCALE

Scale the work.
Not idle infrastructure.

Give serving and processing independent capacity decisions. Run supported workloads on serverless containers, autoscaling node-based clusters, and on-demand batch compute—not one all-purpose server sized for peak load.

Explore deployment topology ↗
04 / OPERATE

Make change routine.
And reversible.

Turn telemetry into findings and remediation suggestions in the Ops Inbox. Use Git-backed configuration, versioned releases, approval controls, and verified recovery for supported changes.

Recovery depends on the operation, deployment, and schema compatibility.
