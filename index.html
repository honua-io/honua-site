Modernize GIS infrastructure
without a big-bang rewrite.

Honua is a source-available GIS server for GIS and platform teams moving beyond ArcGIS Server or GeoServer. Keep supported clients on familiar interfaces, migrate service by service, and run one container beside the PostGIS you already operate. See how the pieces connect → · Read the Honua belief →

Publish across documented GeoServices REST, OGC, OData, STAC, tile, gRPC, and MCP surfaces. Evaluate Community from public source now; the JavaScript SDK is a public prerelease; the operator loop is private beta, and Honua Cloud is planned. Commercial pricing follows production capacity, not users, requests, or data volume.

// three reasons to move

Every reason links to its proof.

01 Operate GIS like the rest of your stack. One-container deployment, health and readiness probes, and OpenTelemetry are available in source today. Private-beta operator tools can prepare plans and pull requests for one environment; broader autonomous recovery remains planned. READ 02 Move one workflow at a time. GeoServices REST, OGC, OData, vector tiles, gRPC, and MCP share one server. Supported ArcGIS Pro, QGIS, Excel, and application workflows can move endpoint by endpoint; the public matrix shows what works and what needs adaptation. READ 03 Price capacity, not headcount. Commercial editions use published annual capacity bands. No named-user seats, request credits, or data-volume billing. Each production node counts against a transparent CPU and memory ceiling.
