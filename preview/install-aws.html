Install Honua in your AWS account.

A customer-operated CloudFormation Launch Stack for design partners evaluating Honua as an Esri alternative.

Honua is at release-candidate stage and has not had a supported release yet. You run the deployment, control the data and pay AWS for the resources in your account.

This installer preview is awaiting a published template and a recorded clean-account install through first sign-in and a first published layer.

Read the install guide

The install button will become available after the install check passes. Contact us about the design-partner programme.

Have these ready.

  • An AWS account and a role allowed to create CloudFormation, IAM and the resources listed in the guide.
  • An operations email address for alerts. Confirm the subscription email AWS sends after deployment.
  • An OpenID Connect identity provider, client ID and client secret, and the administrator role claim. Register the deployed callback URL with your provider before signing in.
  • The operation key-ring certificate stored in Secrets Manager, as described in the guide. Preserve an encrypted recovery copy with your backups.
  • The release image and template supplied for your design-partner evaluation. Use the immutable image reference in the guide.

Choose the stack name, region, Size, Availability and Protection parameters using the guide. Start in us-east-1. Other supported regions require deploying waf.yaml in us-east-1 first.

Your AWS account receives the bill.

AWS charges for the resources you deploy, including application compute, the database, networking and traffic, storage, backups, logging and security services. Size, availability, retention and usage affect the bill. Review the CloudFormation resources before creating the stack.

This is a deployment you operate in your account. Your team handles access, upgrades, monitoring and recovery. The install guide explains the parameters, first sign-in and first-layer checks.

Plan the teardown.

Export the data you need before deleting the stack. Retained database snapshots, buckets, secrets, encryption keys, backup recovery points and logging or security resources may need separate cleanup and can continue to incur AWS charges. Follow the guide’s teardown checklist and verify the remaining resources in your account.
