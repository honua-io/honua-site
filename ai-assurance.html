AI assurance assessment.

Review the scope, status and evidence behind Honua’s AI security assessment.

Assessment recorded: 2026-10-26 · Review due: 2027-01-23

Assessment in progress. No installed release is qualified by this assessment. This dated snapshot must be reviewed after the due date.

Assessment scope

Honua Server; Studio / Console; SDK agent integrations; DevOps agent; Deployment infrastructure; Development-agent workflows. We assess agent permissions and access boundaries within supported deployments.

Excluded: Cross-tenant isolation; External certification; Unconfigured model providers.

Customer-managed deployments require operator evidence for identity configuration, provider terms, network restrictions, secrets, retention and recovery. Any Honua-managed deployment requires its own operational evidence.

Framework alignment status

Honua is assessing its AI capabilities against the frameworks below. These mappings identify work to verify; they do not establish framework equivalence, full compliance, or certification. Honua does not claim ISO/IEC 42001 certification or FedRAMP authorization.

What remains to verify

Provider disclosure policies, delegated authority, protected actions, untrusted context, execution limits, audit records, supply-chain integrity, recovery and geospatial correctness require scoped verification. Management-system approval, training and independent assessment evidence are also pending.

Enabling external models can send prompts, supplied context, report summaries or imagery to the configured provider. Operators must approve the destination and data handling for each enabled use case.

Material changes to models, tools, policies or deployment configuration require reassessment. Missing, skipped, stale and inconclusive results do not count as passes.

Request restricted assessment material through security@honua.io. Availability depends on completion and disclosure review.
